# Revisión de Contenido (Checklist)

Lista de verificación para todo lo que el equipo debe confirmar antes de publicar la página web de la expoferia:

- [ ] Nombre completo del docente
- [ ] Título profesional del docente
- [ ] Fotografía del docente
- [ ] Nombres de los estudiantes
- [ ] Fotografías de los estudiantes
- [ ] Tema de exposición de cada estudiante
- [ ] Instagram de cada estudiante
- [ ] Instagram general del proyecto
- [ ] Fotografía de portada escritorio
- [ ] Fotografía de portada móvil
- [ ] Fotografías de la galería
- [ ] URL de Google Forms
- [ ] URL pública del formulario
- [ ] URL final del sitio
- [ ] Dominio personalizado
- [ ] Tipo exacto de fosfato utilizado
- [ ] Presentación exacta de Rovabio
- [ ] Concentración y etiqueta de Coyden
- [ ] Indicaciones y período de retiro aplicable al Coyden utilizado
- [ ] Tipo de aceite de palma del Tratamiento B en cada fase
- [ ] Fórmula exacta de Tratamiento A en Inicial 1
- [ ] Fórmulas exactas de Crecimiento 1 y Crecimiento 2
- [ ] Confirmar que el último bloque del Tratamiento B corresponde a Finalizador
- [ ] Edades exactas de cada fase
- [ ] Parámetros productivos realmente medidos
- [ ] Resultados reales, si se decide publicarlos
- [ ] Revisión final del docente
- [ ] Autorización para publicar fotografías
- [ ] Revisión del código QR
- [ ] Prueba del NFC
